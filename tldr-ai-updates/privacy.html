Privacy Policy

TLDR AI Updates Uploader · Effective October 9, 2026

The TLDR AI Updates Uploader is a personal software tool operated by Matthew Thomas. It runs on the operator's own computer and uploads short tech-news videos, which the operator produces, to the operator's own YouTube channel, TLDR AI Updates. It is not offered to the public and has no other users.

What the tool accesses

Through the YouTube API Services, and only for the operator's own channel, the tool:

  • uploads videos together with their titles, descriptions and tags;
  • reads the channel's name, to confirm which channel is connected; and
  • reads and updates the visibility (private or public) of videos it uploaded.

It does not access, collect or store data about any other YouTube user: no viewer data, comments, subscriber lists, analytics or other channels.

How information is stored

The Google sign-in token that authorizes uploads is stored only on the operator's computer, in a file readable only by the operator's account. Upload records (video IDs and visibility) and the videos themselves are also kept only on that computer. Nothing is sent to any server other than Google's YouTube API.

Sharing

No information obtained through the YouTube API Services is sold, shared with or disclosed to any third party.

Revoking access

Access can be revoked at any time from the Google Account's Third-party apps & services page, after which the tool can no longer access the channel. Deleting the stored token file on the operator's computer has the same effect.

Google and YouTube

This tool uses YouTube API Services. By using YouTube you are subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
